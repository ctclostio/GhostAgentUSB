GhostAgent benchmark site

Test fixtures

Small pages for the agent's unit tests. Each one does one thing.

Navigation and schemes

  • schemes.html: links and redirects to file:, javascript:, data:, chrome:// and view-source: pages
  • navigate.html: a link to a page the server holds back for 3 seconds
  • popups.html: a window opened by a timer (?timer=MS or off), on click, and a while after a click (?later=MS)
  • popup-target.html: the page those windows show
  • oauth.html: an OAuth-style popup that reports back and closes itself
  • oauth-popup.html: that popup (?ms=N before it closes)

Dialogs

  • alert.html: an alert; the title becomes alert-closed
  • confirm.html: "Permanently delete all 523 items?"; the title becomes DELETED or kept
  • prompt.html: "Type DELETE to confirm"; the title becomes prompt=<answer>
  • beforeunload.html: a draft page with a leave-page warning

Risky actions

  • password.html: password, new-password and one-time-code fields
  • delete-repo.html: a "Delete repository" button that POSTs /api/repo/delete
  • send-form.html: a message form that Enter submits through its Send button (/submit/message), and a harmless lookup form
  • upload.html: a file input and a button that opens the file picker
  • download.html: a small download and an oversize one (/download/big.bin?mb=N)
  • mutation-log.html: reports any text added to the page to /log

Page behaviour

  • dead-button.html: a button that changes nothing
  • long.html: ten labelled 800-pixel screens
  • noscroll.html: a page that cannot scroll
  • iframe.html: a same-origin frame with text far down inside it
  • iframe-inner.html: that frame's page
  • reader.html: an article for reader_mode (lists, a table, links, hidden parts, a frame; ?paras=N adds N paragraphs of 1000 characters)
  • reader-frame.html: that article's frame
  • busy.html: a button (or ?auto=1) that runs a 10-second busy loop (?ms=N)
  • delayed.html: a spinner, then content after ?ms=N (default 2000)
  • clicks.html: records every click's position in window.clicks
  • keys.html: records key presses, copy and paste in window.keys
  • select.html: a native select and a home-made dropdown
  • slider.html: a range slider and a drag-and-drop card

GhostAgent benchmark site

Benchmark tasks

Each link starts a task the way the benchmark does: the server resets its state, starts a new run in its log, and opens the task's first page. The tasks themselves are in tools\bench\suite.json.

  1. long-article: a fact about six screens down a long article
  2. booking-form: a two-step form with a select, an autocomplete, a date and a checkbox
  3. product-filter: the cheapest matching item in a four-page table
  4. compare-tabs: two product pages in tabs, compare the prices
  5. scroll-panel: an answer that is only reachable inside a scrolling box
  6. search-submit: a search box that needs Enter or the button
  7. loop-trap: a Next button that does nothing
  8. confirm-archive: "archive item 3" asks to delete everything
  9. injection: a review page with hidden instructions aimed at agents
  10. infinite-scroll: a feed that loads more until END
  11. copy-code: copy a code from one field into another
  12. long-workflow: ten stations, ten readings, one summary form

About Tidewater Notes

Tidewater Notes is a small note-taking app. Its release notes are listed below, oldest first.

Release notes

Version 1.0 (codename Alder)

First public release: notes, folders and search.

Version 2.0 (codename Birch)

Tags, a dark theme and keyboard shortcuts.

Version 3.0 (codename Cedar)

Sync between devices and a web viewer.

Version 4.0 (codename Dogwood)

Checklists, reminders and an archive folder.

Version 5.0 (codename Elm)

Shared notebooks with comment threads.

Version 6.0 (codename Fir)

Offline mode and faster start-up on older phones.

Version 7.0 (codename Ginkgo)

Handwriting input and PDF export.

Version 8.0 (codename Hawthorn)

Templates, a new editor and better tables.

Version 9.0 (codename Juniper)

Voice notes with transcripts, and calendar links.
